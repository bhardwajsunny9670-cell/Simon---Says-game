# Simon Says Game 

A browser-based memory game built with HTML, CSS, and JavaScript.

## How to Play
- Press any key to start the game
- Watch the sequence of colors that lights up
- Repeat the sequence by clicking the buttons
- Each round adds one more step to the sequence
- One wrong click = Game Over

## What I Learned
- DOM manipulation
- Event listeners
- Game logic with arrays
- CSS animations for button effects

## Tech Stack
- HTML
- CSS  
- JavaScript (Vanilla)
